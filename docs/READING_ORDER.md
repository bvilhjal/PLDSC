# Reading guide

## LDSC in practice

Start with the [LDSC guide](LDSC.md) for installation, file formats, QC and
command-line and Python examples. The [notebook](../examples/ldsc_notebook.ipynb)
is an executable walkthrough; the [methods report](../report/methods.pdf)
describes the equations and their assumptions.

## Multi-ancestry research

Read [MULTI_ANCESTRY.md](MULTI_ANCESTRY.md) for the model, results and
limitations, then [STRATEGY.md](STRATEGY.md) for the research questions and
pre-stated gates. The [experiment index](../experiments/README.md) links the
scripts, results and data requirements. [D1_ANNOTATION_GATE.md](D1_ANNOTATION_GATE.md),
[PROJECT_DIRECTIONS.md](PROJECT_DIRECTIONS.md),
[REAL_DATA_SURVEY.md](REAL_DATA_SURVEY.md) and [STUDENT_PLAN.md](STUDENT_PLAN.md)
provide further research context; some contain superseded proposals.

- [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md), [IDEA_REVIEW.md](IDEA_REVIEW.md),
  [EXTERNAL_REVIEW.md](EXTERNAL_REVIEW.md) and [NOTE_OUTLINE.md](NOTE_OUTLINE.md)
  record the plan and its review.
- [PRIOR_ART.md](PRIOR_ART.md), [GEMMA_PARITY.md](GEMMA_PARITY.md) and
  [WHEN_STRUCTURE_MATTERS.md](WHEN_STRUCTURE_MATTERS.md) contain related

- [Experiment results](../experiments/RESULTS.md) preserve the detailed
